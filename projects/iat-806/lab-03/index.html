Lab 03 — Dancing Dogs

A frame-by-frame animation created with p5.js.

This sketch features a collection of funny dancing dogs. Each dog has its own dance pose, creating a playful frame-by-frame animation on the dance floor.

Click the canvas to start and stop the animation. Sound and other interactions are added to make each dancing dog have its own personality.
